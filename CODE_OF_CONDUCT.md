# Code of Conduct

## Our Standard

Contributors should keep discussions technical, respectful, and focused on the
project. Disagreement is fine. Harassment, threats, hate speech, and personal
attacks are not.

## Unacceptable Behavior

- Insults or targeted harassment.
- Sexualized language or imagery.
- Publishing private information without permission.
- Sustained disruption of issues, pull requests, or discussions.
- Any conduct that would make the project hostile to reasonable contributors.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or block
contributors who violate this code of conduct.

If you need to report a problem, contact the maintainers privately when
possible and include links or screenshots that show the issue.
