# Disclaimer

GAI-1 is an experimental training scaffold. It is not a finished assistant and
does not include production model weights.

The repository provides code for:

- tokenizer training;
- pretraining;
- supervised fine-tuning;
- LoRA adapters;
- quantized checkpoint export;
- local TUI/API serving;
- evaluation scaffolding.

You are responsible for:

- dataset license review;
- safety evaluation;
- privacy review;
- compliance with laws and platform rules;
- validating any model output before use.

Do not use generated outputs for medical, legal, financial, safety-critical, or
other high-stakes decisions without expert review.
